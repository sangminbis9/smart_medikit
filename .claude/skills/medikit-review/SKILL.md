# medikit 변경 검토

공통 검토 원칙은 `AGENTS.md`와 `docs/CONTRIBUTING.md`를 따른다. 상세 프로젝트 판단은 `plan.md` 관련 섹션, 컴포넌트 경계는 `docs/CONTRACTS.md`에서 확인한다.

1. 변경 코드의 함수 앞 간결한 한국어 주석, 핵심 분기 설명, 중복 파일·불필요한 폴더를 점검한다.
2. Pi→AWS→Flutter 이벤트 계약, 중복 차감 방지, 사용자 확인 흐름, 개인정보·의약품 위험정보 표시를 점검한다.
3. 테스트 실행 결과를 확인하고 미검증 항목을 명시한다.
4. 한국어로 **문제점(중요도와 파일 경로) / 검증 / 남은 위험**을 요약한다.
